# Hawcoder (Hawassa, Ethiopia)

> **Hawcoder** (`|=| Hawcoder`) is an independent, non-profit student initiative founded by Hawassa high school alumni of **AddisCoder 2026**.
> Hosted at the **American Corner, Hawassa**, our mission is to teach the foundational computer science and algorithmic problem solving we learned at AddisCoder to high school students in Hawassa, and guide students in applying to the official AddisCoder summer program on time.

---

## ⚠️ Independent Affiliation Disclaimer

**Hawcoder is an independent student-led initiative. We are NOT an official part of, endorsed by, or operated by AddisCoder Inc. or Jelani Nelson.**

- Participation in Hawcoder does **not** guarantee admission into the official AddisCoder program.
- Official AddisCoder admissions and information must be accessed directly at [addiscoder.com](https://www.addiscoder.com).

## 🚀 Ready for 100% Free GitHub Hosting

The project is built as an ultra-fast, zero-cost static website ready to host on **GitHub Pages** for \$0 forever.

### Steps to Push to GitHub & Go Live:

1. **Initialize Git & Commit:**
   ```bash
   cd C:\Users\HP\.gemini\antigravity\scratch\hawcoders-website
   git init
   git add .
   git commit -m "Launch Hawcoder website"
   ```

2. **Connect to Your GitHub Repository:**
   ```bash
   git remote add origin https://github.com/<your-username>/hawcoder.git
   git branch -M main
   git push -u origin main
   ```

3. **Deploy with 1 Command:**
   ```bash
   npm run build
   ```
   (We can also set up automated GitHub Pages deployment so every time you commit, it deploys automatically!)
